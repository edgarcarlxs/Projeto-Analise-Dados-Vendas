# Projeto de Análise de Dados de Vendas 📊

Este projeto foi desenvolvido com o objetivo de consolidar, tratar e analisar dados históricos de vendas. A solução engloba desde a manipulação e consulta em banco de dados relacional até a construção de um painel gerencial interativo.

## 🛠️ Tecnologias Utilizadas
* **SQL:** Construção de consultas complexas (Joins, agregações, funções de janela e tratamento temporário).
* **Power BI:** Modelagem de dados, conexões entre tabelas, criação de colunas calculadas via DAX e design do dashboard.

## 🗂️ Estrutura do Repositório
* `consultas-vendas.sql`: Contém todos os scripts SQL desenvolvidos para as análises descritivas do negócio.
* `dashboard-faturamento.pbix`: Arquivo do Power BI com o modelo de dados e o painel visual construído.
* `relatorio-analise-dados.pdf`: Documentação completa contendo a interpretação de negócio de cada etapa.

## 📈 Principais Insights do Dashboard
* **Faturamento Global:** O faturamento histórico consolidado atingiu a marca de **29 Milhões**.
* **Destaque Comercial:** A categoria de **Meat/Poultry** (Carnes e Aves) lidera de forma isolada com **8,3 Milhões** em receita.
* **Oportunidade de Melhoria:** O setor de **Produce** apresentou a menor performance financeira, gerando **1,6 Milhão**.
